# Telkom University Company Profile - Praktikum  
Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git. 
## Cara Menjalankan Project

Jalankan Apache dan MySQL melalui XAMPP.
Pastikan database `telkom_profile` sudah dibuat.
Simpan project di folder `C:\xampp\htdocs\telkom-company-profile`.
Buka browser dan akses `http://localhost/telkom-company-profile/`.
